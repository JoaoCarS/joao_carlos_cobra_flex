## 📋 Sobre o projeto

O **COBRA FLEX** é uma aplicação web criada para facilitar a decisão de qual combustível utilizar no momento do abastecimento.

O usuário informa o preço da **gasolina** e do **etanol** e, ao clicar no botão **Calcular**, o sistema realiza a comparação entre os combustíveis e apresenta o resultado.

---

## 🎯 Objetivo

O principal objetivo do projeto é tornar mais simples e rápida a comparação entre gasolina e etanol.

Em vez de realizar o cálculo manualmente, o usuário pode informar os preços diretamente na aplicação e receber o resultado automaticamente.

---

## ⚙️ Funcionalidades

- ⛽ Informar o preço da gasolina.
- 🌱 Informar o preço do etanol.
- 🧮 Calcular a relação de custo-benefício.
- 🧮 Cálculo automático da proporção de 75%.
- 📊 Comparar gasolina e etanol.
- ✅ Indicar a opção mais vantajosa.
- 💻 Interface simples e intuitiva.
- 🌐 Aplicação disponível online.

---

## 🧮 Como funciona

A aplicação compara o preço do etanol com o preço da gasolina.

Uma referência bastante utilizada para essa comparação é o percentual de **75%**.
